## Como levantar el proyecto localmente

1 **Clonar el repositorio:**
En git bash colocamos: git clone https://github.com/mauroflesia/Actividad-semana-2-10-Estandares-para-el-desarrollo-web
Accedemos a la carpeta del proyecto: cd Actividad-semana-2-10-Estandares-para-el-desarrollo-web
Cambiamos a la rama first-version: git switch first-version
Para visualizar el sitio tenemos 2 opciones: 
1: Abrir el archivo index.html con doble clic sobre el archivo.
2: En VSCode, buscamos la extension llamada Live Server, la instalamos, luego nos situamos en el archivo index.html, apretamos clic derecho y la opcion "Show Preview"
